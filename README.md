Projeto de Analise de dados com IA.

Imagine que você trabalha em um banco e tem uma base de dados de 100.000 clientes e precisa verificar o score (pontuação) dos clientes para classificá-los. Isso vai definir se ele vai ter crédito no banco, entre outros benefícios. 
Nosso objetivo é fazer um tratamento na base de dados, criar alguns algoritmos de classificação e verificar qual deles é o melhor.
Desta forma conseguiremos fazer uma previsão dos clientes para saber se eles terão um bom "score" ou não.

Por ser um projeto voltado para análise de dados, é fundamental realizar o tratamento e a análise dos dados para chegar ao resultado esperado.

Foram realizados os seguintes passos nbessa análise:
• Importação da base de dados
• Verificaçção de informações vazias
• Tratamento da base de dados
• Seleção das colunas de treino para o modelo
• Treinamento de 2 modelos
• Verificação do melhor modelo
• Verificação de quais as características mais importantes para definir o score do cliente
